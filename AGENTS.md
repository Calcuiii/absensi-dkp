# Aturan kerja repository

- Sebelum membuat atau mengubah sesuatu untuk pekerjaan baru, buat dan gunakan branch baru terlebih dahulu.
- Gunakan nama branch yang menjelaskan pekerjaan, misalnya `chore/setup-development-environment` atau `feat/mobile-login`.
- Lanjutkan pekerjaan yang masih sama di branch pekerjaannya; jangan membuat perubahan langsung di branch utama.
